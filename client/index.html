About The System

Built for caregivers who need confidence, context, and speed.

ElderGuard combines biomedical sensing with cloud-backed analytics. Arduino hardware captures continuous vitals and motion activity, Node.js APIs process incoming payloads, and MongoDB stores records for historical insight.

The interface is designed for instant readability under pressure: strong hierarchy, clear status cues, and emergency-focused visual patterns.

Sensor Stack

  • MAX30102 for BPM and SpO2
  • LM35 for body temperature
  • ADXL345 for fall pattern detection
  • NEO-6M for GPS latitude and longitude

How It Works

From wearable sensing to caregiver decision support.

01

Sensing

Vitals, motion, and location data are sampled by Arduino-connected sensors.

02

Transmission

Data is transmitted securely to the Node.js backend through WiFi payloads.

03

Processing

Server-side validation and storage in MongoDB create dependable live + history data.

04

Visualization

The dashboard presents cards, charts, alerts, and map context in real time.
